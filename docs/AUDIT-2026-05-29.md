## Overall assessment

A genuinely strong, well-engineered portfolio with disciplined color use, sound animation-cost engineering (capped-DPR particles, IntersectionObserver gating, motion guards), and a correct mobile focus trap. **Two true blockers** are worth fixing first: project links are unreachable on touch devices (recruiters on phones can't open any repo), and the About portrait — a likely LCP element — ships a 188 KB baseline JPEG with no `sizes`/blur. The **biggest perceived-polish lever** is unifying the three competing section-header treatments into one rhythm. Everything else is high-quality craft + contrast cleanup that is safe to ship.

## Blockers (fix first)

### 1. 🔴 CRITICAL — Project repo/live links unreachable on every touch device
- **Location:** `src/components/Projects.tsx:98`
- **Problem:** The per-card action links sit in an `opacity-0 group-hover:opacity-100 focus-within:opacity-100` container. The card is a non-interactive `<div>`, and touch devices have no hover and never trigger `focus-within`, so the GitHub/live links are permanently invisible on phones/tablets — the section's primary CTA is dead on the platforms most recruiters use.
- **Fix:** `opacity-100 [@media(hover:hover)]:opacity-0 [@media(hover:hover)]:group-hover:opacity-100 focus-within:opacity-100` — always-visible on touch, keeps the desktop hover reveal.
- **Effort:** S · **Risk:** safe · **Status:** ✅ applied

### 2. 🟠 HIGH — About portrait (likely LCP) ships 188 KB baseline JPEG, no sizes/blur, into ~340px box
- **Location:** `src/components/About.tsx:88-94`; `public/avatar.jpeg` (188 KB, 900×1200 baseline)
- **Problem:** No `sizes` → Next defaults to a 100vw srcset and the browser may pick an oversized candidate; no blur → hard pop-in. Source is a non-progressive 188 KB JPEG rendered in a 300–340px frame.
- **Fix:** Add `sizes="(max-width: 640px) 300px, 340px"` and `placeholder="blur"` with a blurDataURL (or static import to auto-generate). Keep width/height 900/1200.
- **Effort:** S · **Risk:** safe · **Impact:** largest single byte reduction on the page (~70–85% on the portrait), smoother perceived load, removes portrait CLS.

### 7. DataVisualization canvas uses uncapped devicePixelRatio
- **Location:** `src/components/DataVisualization.tsx:47`
- **Problem:** `window.devicePixelRatio || 1` with no cap while ParticleNetwork caps at 2. On a 3× phone the backing store is 9× the needed pixels, inflating the heaviest per-frame loop (a gradient per connection per frame).
- **Fix:** `const dpr = Math.min(window.devicePixelRatio || 1, 2);`
- **Effort:** S · **Risk:** safe

### 19. Reserve two-line height on the scramble h1 (CLS)
- **Location:** `src/components/Hero.tsx:251-259`
- **Problem:** Initial fallback is a single ` ` (one line) but resolved text is two lines via `whitespace-pre-line`, so the h1 can grow 1→2 lines mid-animation — a layout shift on the largest above-the-fold text.
- **Fix:** Render fallback as a two-line value (`' \n '`) or set a `min-height` matching two lines. Pairs with #13.
- **Effort:** S · **Risk:** safe

### 20. Convert avatar.jpeg master to AVIF/WebP and reuse everywhere

## Accessibility

### 4. slate-500 functional labels/captions below 4.5:1 AA
- **Location:** `Contact.tsx:225,241,259,276` (form labels); `About.tsx:196` (Quick Facts labels); mono captions across Hero/Skills/DataVisualization
- **Problem:** `text-slate-500` (#64748b) = 4.26:1 on navy, 4.05:1 on surface, 3.55:1 on surface-3 — below the 4.5:1 AA threshold for normal text.
- **Fix:** Replace `text-slate-500` → `text-slate-400` (#94a3b8, ~6.6–7.9:1) for functional label/caption text. At minimum the four Contact form labels + About Quick Facts labels. Stays in-palette.
- **Effort:** S · **Risk:** safe

### 5. slate-600 footer text + form placeholders fail badly (2.2–2.7:1)
- **Location:** `Footer.tsx:76,79`; `Contact.tsx:237,253,271,288` (`placeholder:text-slate-600`)
- **Problem:** slate-600 (#475569) = 2.2–2.7:1 — below even the 3:1 large-text floor. Placeholder hints effectively invisible.
- **Fix:** `placeholder:text-slate-600` → `placeholder:text-slate-400` on the four inputs/textarea; two footer `<p>` `text-slate-600` → `text-slate-400`.
- **Effort:** S · **Risk:** safe

### 13. Guard role-cycle + scramble against prefers-reduced-motion
- **Location:** `Hero.tsx:180-185` (setInterval role cycle), `18-64` (useTextScramble)
- **Problem:** Global CSS reduced-motion only neutralizes CSS animation; these are JS state loops. Role text swaps every 2800ms and the 35ms scramble runs unconditionally (unlike the parallax at line 188 which IS guarded).
- **Fix:** Early-return the role-cycle effect when `matchMedia('(prefers-reduced-motion: reduce)').matches`; in useTextScramble, on reduced motion immediately `setDisplay(text)`/`setDone(true)` and skip the tick loop.
- **Effort:** S · **Risk:** safe

### 14. role="alert" on form error + announce success
- **Location:** `Contact.tsx:309-313` (error `<p>`); success block (~199-220); submit button 297-301
- **Problem:** Error renders as a plain `<p>` with no role/aria-live; success swap + "Sending…" state have no live region. (red-400 color passes; only semantics missing.)
- **Fix:** `role="alert"` on the error `<p>`; wrap success container with `role="status" aria-live="polite"`. Optionally `id="form-error"` + `aria-describedby` on submit.
- **Effort:** S · **Risk:** safe

### 15. Skip-to-content link
- **Location:** `src/app/page.tsx` (first child of `<main>`)
- **Problem:** No skip link; keyboard users tab through logo + up to 7 nav links + Hire Me before content (WCAG 2.4.1).
- **Fix:** `<a href="#about" className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[200] focus:px-4 focus:py-2 focus:rounded-lg focus:bg-accent-blue focus:text-white">Skip to content</a>` (`#about` already exists).
- **Effort:** S · **Risk:** safe

## Visual design

### 3. 🟠 Three incompatible section-header treatments break the page rhythm
- **Location:** `About.tsx:44-73` (watermark, no underline); Skills/Experience/Credentials/Interests/Contact (mono eyebrow + animated underline); `Projects.tsx:170-207` (right-aligned, gradient numeral, no underline)
- **Problem:** Three unrelated header systems — on a single-page scroll the eye never learns one rhythm; each section reads as pasted from a different template. Top lever separating "strong template" from "premium".
- **Fix:** Adopt the inline mono-eyebrow + heading + animated-underline pattern (already used by 5 of 7) as canonical. Refit About (drop watermark 46-54, use "01. ABOUT" eyebrow) and Projects (remove right-aligned block + separate gradient numeral, use left-aligned "04. PROJECTS"). Best via a shared `SectionHeader` (see #11).
- **Effort:** M · **Risk:** subjective · **Status:** 🟡 owner call.

### 8. Tighten display heading tracking
- **Location:** `Hero.tsx:255` (h1, text-8xl); all section h2 (text-4xl sm:text-5xl)
- **Problem:** Exo 2 is a wide geometric face at default tracking even at 8xl/5xl — reads slightly loose/"webby"; display + mono eyebrows share neutral spacing, flattening contrast.
- **Fix:** Add `tracking-tight` (or `-tracking-[0.02em]`) to Hero h1 + every section h2; leave mono eyebrows at tracking-widest.
- **Effort:** S · **Risk:** subjective · **Status:** 🟡 owner call.

### 16. Switch Hero scramble charset from punctuation to letters
- **Location:** `Hero.tsx:16` (SCRAMBLE_CHARS), `165`
- **Problem:** Scrambles the owner's NAME through pure punctuation (`@#$%^{}|:`) — on a proper noun reads as broken/garbage rather than a deliberate ~1.5s decode, in the highest-stakes 3 seconds of the site.
- **Fix:** `SCRAMBLE_CHARS = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'` (or letters+digits). Optionally shorten 1500→~1000ms. Pair with #13.
- **Effort:** S · **Risk:** subjective · **Status:** 🟡 owner call.

### 17. Make featured Skills tiles lead at rest + remove dead ternary
- **Location:** `Skills.tsx:161` (no-op `${skill.featured ? '' : ''}`); 187-192 (Core skill dot)
- **Problem:** className ternary returns `''` in both branches; featured skills (Python, Pandas, ML, GenAI) get no distinct container treatment.
- **Fix:** Replace no-op with a real palette-safe treatment, e.g. `${skill.featured ? 'border-accent-blue/30 shadow-[0_0_24px_var(--glow)]' : ''}`, or delete the fragment to keep tiles uniform.
- **Effort:** S · **Risk:** subjective · **Status:** 🟡 owner call (dead-ternary removal alone is safe).

### 18. Variable-step section padding (2-tier scale)
- **Location:** all sections (py-28)
- **Problem:** Identical py-28 regardless of density — metronomic rather than musical; light sections feel over-padded next to dividers.
- **Note:** CLAUDE.md mandates py-28 for consistency → owner taste call, not a free change.
- **Fix (if desired):** 2-tier scale (py-28 dense, py-24 for Interests/Credentials) as a system, and update the CLAUDE.md rule.
